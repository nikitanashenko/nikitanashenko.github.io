1.1 — Convolutions from Scratch

The 4-loop version works by cycling through each pixel in the original image, and then for each pixel, applying the (flipped) kernel using that pixel as the center. The kernel is applied one entry at a time. The 2-loop version similarly goes through each pixel in the original image, but at each pixel it applies the whole kernel at once using matrix operations. Both zero-pad the image so the output is the same size as the input.

1.2 — Finite Difference Operator

Convolving with Dx and Dy gives the horizontal and vertical intensity changes, and the gradient magnitude is sqrt(dx² + dy²). To get an edge image, I binarized the magnitude with a threshold. I chose t = 0.30 because the noise was reasonably suppressed while still leaving good edges: lower thresholds kept much of the grass texture, and higher ones started breaking up the real edges. The thin bright border comes from zero padding.

1.3 — Derivative of Gaussian (DoG)

I built G with cv2.getGaussianKernel (7×7, σ = 1) and an outer product with its transpose. I compared two approaches: blurring first and then applying Dx/Dy, versus convolving G with Dx and Dy to get DoG filters and applying them in a single convolution. Compared to 1.2, there is less grass noise and the edges are smoother and thicker. The threshold dropped to 0.10 because smoothing lowers the gradient magnitudes. The two methods match in the interior (convolution is associative) but differ at the border because of zero padding.

Part 2: Fun with Frequencies

2.1 — Image "Sharpening"

The Gaussian blur is a low-pass filter, so image − blur leaves the high frequencies, and the sharpened image is image + α·(image − blur). The unsharp mask filter combines the blur and sharpen steps into one convolution with the kernel (1+α)·δ − α·G, which gives the same result as the 3-step version. A larger α makes edges crisper.

Evaluation: Blur, Then Re-sharpen

Blurring and then re-sharpening makes the image look a lot flatter: the blur removes the high frequencies, and sharpening can't retrieve them, since it only amplifies frequencies that are still there.

2.2 — Hybrid Images

Hybrids work by overlaying the high frequencies of one image onto the low frequencies of another. From far away you see the low-frequency image, while up close the high-frequency image dominates. The sigmas set the size of each smoothing kernel, which controls the cutoff frequency for each image. The images were aligned with two clicked points; the faint diagonal lines are the edges of the rotated image, which the high-pass filter keeps.

2.3 — Gaussian and Laplacian Stacks

The Gaussian stack repeatedly blurs the image without downsampling. The Laplacian stack is G[i] − G[i+1] for each level, plus the last Gaussian level, so each level holds one band of frequencies. Summing the Laplacian stack gives back the original image (verified with np.allclose).

Figure 3.42 Recreation

Rows are Laplacian levels 0, 2, and 4, plus the sum over all levels. Columns are the masked apple, the masked orange, and the blend. The fine levels switch sharply at the seam, while the coarse levels cross-fade over a wide band.

2.4 — Multiresolution Blending

I build Laplacian stacks of both images and a Gaussian stack of the mask, then at each level compute mask·L1 + (1 − mask)·L2 and sum all the levels. This gives a sharp transition for fine detail and a wide one for colors, so the seam disappears.
