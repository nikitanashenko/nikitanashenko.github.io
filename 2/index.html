1.1 — Convolutions from Scratch

The 4-loop version works by cycling through each pixel in the original image, and then for each pixel, applying the (flipped) kernel using that pixel as the center. The kernel is applied one entry at a time. The 2-loop version similarly goes through each pixel in the original image, but at each pixel it applies the whole kernel at once using matrix operations. Both zero-pad the image so the output is the same size as the input.

1.2 — Finite Difference Operator

Dx and Dy show intensity changes in the horizontal and vertical directions. The gradient magnitude is sqrt(Dx² + Dy²), which I binarized with a threshold. I chose t = 0.30 because the noise was reasonably suppressed while still leaving good edges: lower thresholds kept a lot of grass noise, and higher ones started breaking up real edges like the coat, tripod, and skyline. 1.3 — Derivative of Gaussian (DoG)

I built the Gaussian G with cv2.getGaussianKernel (7×7, σ = 1) and an outer product. First I blurred the image and then applied Dx and Dy; then I convolved G with Dx and Dy to get DoG filters and applied them in a single convolution. Compared with 1.2, the results have much less grass noise and smoother, thicker edges. The best threshold dropped to 0.10 because smoothing lowers the gradient magnitudes. The two methods match exactly in the interior (np.allclose = True), since convolution is associative; they differ only at the border because of zero padding.

Part 2: Fun with Frequencies

2.1 — Image "Sharpening"

The Gaussian blur keeps only low frequencies, so image − blur gives the high frequencies, and the sharpened image is image + α·(image − blur). Unsharp masking combines the blur and sharpen steps into one convolution with the kernel (1+α)·δ − α·G, which gives the same result. Higher α looks crisper but eventually adds halos and noise.

Evaluation: Blur, Then Re-sharpen

Blurring and then re-sharpening makes the image a lot flatter: the blur removes the high frequencies, and the sharpening can't retrieve them, since it only amplifies frequencies that are still there. Edges look crisper, but fine detail doesn't come back.

2.2 — Hybrid Images

Hybrids work by overlaying the high frequencies of one image onto the low frequencies of another. At long distances you see the low-frequency image, while up close the high frequencies dominate and you see the high-frequency image. The sigmas set the size of each smoothing kernel, which chooses the cutoff frequencies. The images are aligned using two clicked points; the faint diagonal lines are the rotated image border, which the high-pass filter keeps.

2.3 — Gaussian and Laplacian Stacks

The Gaussian stack repeatedly blurs the image with a Gaussian without downsampling, so every level is the same size. The Laplacian stack takes the difference between neighboring Gaussian levels, G[i] − G[i+1], so each level holds one band of frequencies, with the last Gaussian level appended at the end. Summing the Laplacian stack gives back the original image exactly (verified with np.allclose).

2.4 — Multiresolution Blending

Each image is split into a Laplacian stack, and the mask into a Gaussian stack. At each level, the two Laplacian levels are combined with mask·L1 + (1 − mask)·L2, and all the levels are summed. Because the mask is blurred more at coarser levels, fine details get a sharp transition (no ghosting) while broad colors blend over a wide region (no visible seam).
