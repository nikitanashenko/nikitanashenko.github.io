Removing the Learning Rate Scheduler

To compensate for removing the scheduler, I trained the same model with a constant learning rate of 1e-3, the rate the scheduler decays to by its final epoch. With a scheduler, a high learning rate at the start lets the model move quickly toward a minimum, and lowering it later lets the model settle into a local minimum. With a constant, lower learning rate, the model instead takes smaller, steadier steps toward the local minimum in its current neighborhood. In doing this, we trade the ability to take large steps across the loss landscape for the ability to find a local minimum much more quickly, since the model starts descending toward it from the very first step instead of first jumping around the neighborhood.

The early epochs show this best: epoch 1 of the scheduled run is still noisy, while epoch 1 of the no-scheduler run is already relatively clean. The scheduled run's loss also spikes at the very start, which suggests that 1e-2 is too large for the first steps. As we approach epoch 10, however, both versions look much closer in appearance, because both are approaching a local minimum.

Removing the scheduler helped in terms of time, as it lowered the number of epochs needed to achieve the same result as the scheduled run.
